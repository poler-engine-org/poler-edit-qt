Палітра команд (Ctrl+K)

Єдина точка входу до всіх дій, тем, форматів, експорту та навігації по файлах прямо з клавіатури, як у VS Code та Obsidian.

Ієрархічний зміст (Outline)

Автоматичне парсинг H1..H6 з інтерактивним згортанням, швидким фільтром та синхронним скролом як у ридері, так і в коді.

🎨

5 Контрастних тем

Откалібрований контраст 14:1 для GitHub Light, Newsprint (газетна сепія), Whitey, Night (OLED) та Breeze Dark.

📌

Кольорові стікери та замітки

Бічна панель із 4 відтінками (янтар, смарагд, роза, графіт). Швидке прикріплення думок до розділів та вставка в текст у два кліки.

🧘

Дзен-режим фокусу

Приховує меню, панелі та статус-бар по Ctrl+Alt+Z. Залишається лише аркуш тексту; вихід за допомогою Esc.

💾

Zero-Copy Piece-Table (10+ ГБ)

Файли розміром 1 ГБ відкриваються за 0.26с. Пам'ять O(1) ≤ 48 МБ завдяки суверенному Rust-ядру на mmap.

📤

Повний пакет експорту

Генерація векторних PDF із пагінацією, стилізованого або чистого HTML, знімків сторінок у PNG, Word (.docx), ODT, RTF та LaTeX.

⌨

Вбудований термінал (F4)

Вбудований термінал із підтримкою poler-sh, bash та PowerShell. Відправка виділеного коду прямо в шелл.

🔍

Потоковий пошук без блокування інтерфейсу, підсвічування бурштиновими маркерами та циклічна навігація за Enter.

📊

Статистика читання
